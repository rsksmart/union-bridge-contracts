# PegStatus
[Git Source](https://github.com/rsksmart/union-bridge-contracts/blob/68c14faa89612dfba1b7e9abf29455625661476f/src/interfaces/IPegCommonTypes.sol)

Represents the current status of a peg-in or peg-out operation

*Tracks the progression of funds through the bridge system*


```solidity
enum PegStatus {
    NOT_REGISTERED,
    REGISTERED,
    ACCEPTED,
    USER_TAKE,
    OP_SELECTED,
    ADVANCED,
    KICKOFF,
    CHALLENGE,
    REVEALED,
    COMPLETED,
    BLOCKED,
    LENGTH
}
```
